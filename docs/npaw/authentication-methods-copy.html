Authentication Methods

To access our Analytics API, CDN APIs, and Admin API, you'll need a valid token. Follow the steps below to create one, or use the simpler header-based authentication method.

📘

ESSENTIAL TO START

Before you start, make sure that you have:

  • account_code: It's your unique identifier.
  • api_key: It's your security key.

Authentication Methods

You can authenticate your API calls using two different methods depending on your use case:

Method 1: Header Authentication

Perfect for: Internal scripts, automation, development, and testing

⚠️

SECURITY WARNING

Only use for internal, server-to-server jobs. Never expose in browsers, mobile apps, or customer-facing code.

Use your API key directly in the request headers - ideal when you control the environment and need quick, reliable access.

Use Cases:

  • 🔧 Internal Scripts & Automation: Cron jobs, data pipelines, monitoring scripts
  • 🧪 Development & Testing: API exploration, debugging, rapid prototyping
  • 📊 Internal Dashboards: Company-internal analytics tools and reports
  • 🔄 System Integration: Connecting NPAW data to your internal systems

Headers:

npaw-api-key: YOUR_API_KEY

Example:

curl -H "npaw-api-key: YOUR_API_KEY" \
     "https://api.npaw.com/ACCOUNT_CODE/data?metrics=views&granularity=hour"

🔐 Security Best Practices for Header Authentication

📋

API Key Management Requirements

  • ✅ Set expiration dates: Always configure an expiration date when creating API keys
  • 🔄 Rotate regularly: Replace API keys every 60–90 days
  • 🔒 Use secret managers: Store keys in secure secret management systems (AWS Secrets Manager, Azure Key Vault, etc.)
  • 👥 Role-based access: Restrict API key permissions by role and scope
  • 📊 Enable audit logging: Monitor and log all API key usage
  • ⚠️ Administrator keys: Only use Administrator-level keys when strictly necessary

Method 2: Token Generation (Time-Limited Access)

Perfect for: External access, BI tools, third-party integrations, and shared access

Generate time-limited tokens with MD5 hash - ideal for controlled external access and when you need expiration control.

Use Cases:

  • 📈 Business Intelligence Tools: Tableau, Power BI, Looker integrations
  • 🤝 Third-Party Access: Sharing data with partners, vendors, or consultants
  • 👥 Client Access: Providing customers with limited-time data access
  • 🔐 Temporary Access: Time-limited access for specific projects or users
  • 📱 Public-Facing Applications: Mobile apps, customer portals, external dashboards

Step-by-step to generate the token

Step 1: Import necessary libraries and set up your account credentials (account code and API key).

Step 2: Define parameters such as token lifespan, metrics, date range, granularity, type of views, filters, and output file format.

Step 3: Create your initial API request URL by combining the above parameters.

Step 4: Generate a secure token by encrypting the account code, initial URL, and API key.

Step 5: Complete your API request URL by adding the generated token, and finally send your request to the API.

import java.net.HttpURLConnection;
import java.net.URL;
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.zip.GZIPInputStream;

public class HeaderAuthExample {

    public static void main(String[] args) throws IOException {
        String account_code = "ACCOUNT_CODE"; // Your Account Code from Admin > Account > Account Code
        String api_key = "API_KEY"; // Your API Key from Admin > Security > API Key
        String host = "https://api.npaw.com";
        
        // Simple API call using headers
        String url = host + "/" + account_code + "/data?metrics=views&granularity=hour";
        String response = sendGetWithHeader(url, api_key);

        System.out.println("URL: " + url);
        System.out.println("Header: npaw-api-key: " + api_key);
        System.out.println(response);
    }

    private static String sendGetWithHeader(String url, String apiKey) throws IOException {
        URL obj = new URL(url);
        HttpURLConnection con = (HttpURLConnection) obj.openConnection();
        con.setRequestMethod("GET");
        con.setRequestProperty("npaw-api-key", apiKey);  // Header authentication
        con.setRequestProperty("User-Agent", "Mozilla/5.0");
        con.setRequestProperty("Accept", "*/*");

        BufferedReader in;
        if ("gzip".equals(con.getContentEncoding())) {
            in = new BufferedReader(new InputStreamReader(new GZIPInputStream(con.getInputStream())));
        } else {
            in = new BufferedReader(new InputStreamReader(con.getInputStream()));
        }

        String inputLine;
        StringBuilder content = new StringBuilder();
        while ((inputLine = in.readLine()) != null) {
            content.append(inputLine);
        }

        in.close();
        con.disconnect();
        return content.toString();
    }
}

import (
	"fmt"
	"io/ioutil"
	"net/http"
)

func main() {
	apiKey := "API_KEY" // Your API Key from Admin > Security > API Key
	accountCode := "ACCOUNT_CODE" // Your Account Code
	host := "https://api.npaw.com"

	// Simple API call using headers
	url := fmt.Sprintf("%s/%s/data?metrics=views&granularity=hour", host, accountCode)

	client := &http.Client{}
	req, err := http.NewRequest("GET", url, nil)
	if err != nil {
		fmt.Printf("Error creating request: %v\n", err)
		return
	}

	req.Header.Add("npaw-api-key", apiKey)

	response, err := client.Do(req)
	if err != nil {
		fmt.Printf("Error making request: %v\n", err)
		return
	}
	defer response.Body.Close()

	respBody, err := ioutil.ReadAll(response.Body)
	if err != nil {
		fmt.Printf("Error reading response body: %v\n", err)
		return
	}

	fmt.Printf("URL: %s\n", url)
	fmt.Printf("Header: npaw-api-key: %s\n", apiKey)
	fmt.Printf("Status: %s\n", response.Status)
	fmt.Print(string(respBody))
}

    public static String getMd5(String input) {
        try {
            // Static getInstance method is called with hashing MD5
            MessageDigest md = MessageDigest.getInstance("MD5");

            // digest() method is called to calculate message digest
            // of an input digest() return array of byte
            byte[] messageDigest = md.digest(input.getBytes());

            // Convert byte array into signum representation
            BigInteger no = new BigInteger(1, messageDigest);

            // Convert message digest into hex value
            String hashtext = no.toString(16);
            while (hashtext.length() < 32) {
                hashtext = "0" + hashtext;
            }

            return hashtext;
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException(e);
        }
    }

        con.setRequestProperty("Accept-Encoding", "gzip, deflate");
        con.setRequestProperty("Accept", "*/*");
        con.setRequestProperty("Connection", "keep-alive");

        BufferedReader in;
        if ("gzip".equals(con.getContentEncoding())) {
            in = new BufferedReader(new InputStreamReader(new GZIPInputStream(con.getInputStream())));
        } else {
            in = new BufferedReader(new InputStreamReader(con.getInputStream()));

        String inputLine;
        StringBuilder content = new StringBuilder();
        while ((inputLine = in.readLine()) != null) {
            content.append(inputLine);
        }

        in.close();
        con.disconnect();
        return content.toString();
    }
